# AGNES Video 2.5 Prompt Skill

AGNES AI 视频生成提示词技能包，支持 **Text、Keyframe、Reference** 三种模式。

## 功能
- 根据创意生成可直接使用的视频提示词
- 支持文生视频、首尾帧控制和多模态参考
- 提供主体场景、动作变化、镜头语言、视觉风格、声音节奏和一致性约束
- Reference 素材限制：最多 5 张图片、3 段音频、1 个视频

## 使用
阅读根目录的 [SKILL.md](./SKILL.md)，将其中的技能说明交给兼容 Skill 的 AI 助手使用。
